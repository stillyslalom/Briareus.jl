Mode analysis

Briareus.legendre — Method
legendre(l, μ)

Legendre polynomial Pₗ(μ).

Briareus.legendre_moments — Method
legendre_moments(values, target, elems; lmax = 8, axis = ẑ, center = mode_center(target, elems), level = 3) -> Vector

Legendre coefficients aₗ (index l+1) of the azimuthally averaged field, aₗ = (2l+1)/(4π) ∫ f Pₗ(cosθ) dΩ, where θ is measured from axis about center and values[e] is indexed by element (taken constant over each element). aₗ/a₀ is the usual "Pₗ/P₀" asymmetry. legendre_weights precomputes the linear operator.

source
Briareus.legendre_weights — Method
legendre_weights(target, elems; lmax = 8, axis = ẑ, center = mode_center(target, elems), level = 3) -> Matrix

Matrix W with legendre_moments(values, …) == W * values[elems]: W[l+1, k] = (2l+1)/Ω ∫ Pₗ(cosθ) dΩ over element elems[k], integrated over 4^level sub-triangles per facet with exact solid angles, and Ω the total solid angle of elems (4π for a closed surface around center). Treating the field as constant on each element makes a uniform field have no l > 0 moments, however the facets tile the sphere.

Briareus.mode_amplitude — Method
mode_amplitude(c, l) -> Real

Rotation-invariant amplitude of degree l relative to the mean, in the normalization of Legendre moments: √((2l+1) Σₘ (c_lm/c_00)²). It equals |aₗ/a₀| for a field axisymmetric about any axis, so for l = 1 it is the fractional amplitude ε of a dipole drive 1 + ε cos γ, the quantity hot-spot velocity sensitivities refer to.

source
Briareus.mode_center — Method
mode_center(target, elems) -> Vec3

Centre about which the mode analysis of elems (legendre_weights, ylm_weights and the scenario caches built from them) measures directions by default: the centre of their SphereSurface when every element lies on sphere components with one centre (a capsule, also when it is offset from chamber centre), otherwise the origin. Analysing an offset capsule about the origin mixes its P2 into a spurious mode 1 at first order in the offset (0.74 % of mode 1 per 100 µm on a 0.83 mm capsule with P2/P0 ≈ −0.1).

source
Briareus.mode_index — Method
mode_index(l, m) -> Int

Position of the real spherical harmonic (l, m) in the flat ordering used by ylm_weights: l² + l + m + 1, i.e. (0,0), (1,-1), (1,0), (1,1), (2,-2), ….

source
Briareus.mode_power — Method
mode_power(C; m = :all) -> Vector

Per-l amplitude σₗ = √(Σₘ cₗₘ²) / c₀₀ from ylm_moments (index l+1; ylm_matrix turns flat coefficients into C), a rotation-invariant nonuniformity spectrum: the rms of the field over the sphere relative to its mean is √(Σ_{l≥1} σₗ²) (mode_rms). Equals |aₗ/a₀|/√(2l+1) for an axisymmetric field. m = :zero keeps only the zonal harmonic m = 0 of each degree (|c_l0|/c₀₀, the spectrum of the azimuthally averaged field, |aₗ/a₀|/√(2l+1) from its legendre_moments) and m = :nonzero the rest; their squares add to the :all spectrum's. The zonal part depends on the polar axis the coefficients were taken about; :all does not.

source
Briareus.mode_rms — Method
mode_rms(c, lmax; m = :all) -> Real

RMS nonuniformity over degrees 1 ≤ l ≤ lmax, σ = √(Σₗ Σₘ c_lm²) / |c₀₀|, from flat real-harmonic coefficients c (mode_index order: ylm_weights(…) * values, or flux_ylm): the rms deviation of the field over the sphere relative to its mean, with the degrees above lmax filtered out (σ² = Σₗ σₗ² with σₗ from mode_power). With m = :zero only the zonal harmonics m = 0 are summed (the rms of the azimuthally averaged field about the coefficients' polar axis), with m = :nonzero only the rest; mode_rms(c, l; m = :zero)^2 + mode_rms(c, l; m = :nonzero)^2 == mode_rms(c, l)^2 up to rounding. The split is the m = 0 / m ≠ 0 decomposition of polar-direct-drive designs (Yeamans et al., Nucl. Fusion 61, 046031, 2021); the filtered σ over l ≤ 30 is the illumination nonuniformity of Barlow et al. (PRL 133, 175101, 2024).

Generic in the number type (it sits on the optimization path). It has a square root, so its derivative is singular for an exactly uniform field; objectives can sum relative_mode_power over l instead, which is σ² without the root.

For hard-sphere laser illumination (no plasma: every ray straight, the incident I cos ψ absorbed where it lands) the field is the absorbed intensity of a deposit on a bare sphere, t = Target(Component(:capsule, icosphere_mesh(R; n), material; surface = SphereSurface(R))), with dep.element ./ t.elem_area projected by W = ylm_weights(t, 1:nelements(t); lmax = 30), built once (DepositionOperator(t, beams; ncone = 1) for collimated beams). The element values average the illumination over each facet, which lowers σₗ at second order in the element size: on OMEGA's 60 beams with SG4 spots on R = 0.5 mm, σ (l ≤ 30) is 3.5 % low at n = 20 (edges 0.055 R) and 1.7 % low at n = 30; a Richardson extrapolation of the two is 0.3 % low (reference/research-notes.md, "Hard-sphere direct-drive illumination").

source
Briareus.relative_mode_power — Method
relative_mode_power(c, l) -> Real

Σₘ (c_lm / c_00)² from flat coefficients c (mode_index order): the squared rotation-invariant amplitude of degree l relative to the mean. Smooth (no square root), so suited to objectives; mode_power is its square root. For an axisymmetric field it equals (aₗ/a₀)² / (2l+1).

Briareus.solid_angle — Function
solid_angle(target, e, center) -> Float64

Exact solid angle subtended by element e at center (Van Oosterom–Strackee formula summed over its triangles). Mode decompositions use it as the quadrature weight, so the weights of a closed surface around center sum to exactly 4π.

source
Briareus.ylm_frame — Method
ylm_frame(axis) -> (ẑ, x̂, ŷ)

Right-handed frame for spherical harmonics with the polar axis along axis. For the default axis = ẑ this is the chamber frame, so azimuthal mode phases are relative to +x (NIF: the direction of Switchyard 1).

source
Briareus.ylm_matrix — Method
ylm_matrix(c, lmax) -> Matrix

Flat coefficients (mode_index order) as the (lmax+1) × (2lmax+1) matrix C[l+1, lmax+1+m] used by ylm_moments and mode_power (unused entries zero).

source
Briareus.ylm_moments — Method
ylm_moments(values, target, elems; lmax = 8, axis = ẑ, center = mode_center(target, elems), level = 2) -> Matrix

Coefficients of real orthonormal spherical harmonics, c[l+1, l+1+m] for -l ≤ m ≤ l (m > 0: cos mφ, m < 0: sin |m|φ), with the polar axis along axis (field constant on each element, harmonics integrated over each facet; see ylm_weights). Use mode_power for rotation-invariant per-l amplitudes.

source
Briareus.ylm_weights — Method
ylm_weights(target, elems; lmax = 8, axis = ẑ, center = mode_center(target, elems), level = 2) -> Matrix

Matrix W with W * values[elems] the coefficients of real orthonormal spherical harmonics in the flat mode_index ordering: Y_l0 = P̄_l0, Y_lm ∝ cos mφ for m > 0 and ∝ sin |m|φ for m < 0, without the Condon–Shortley phase, so Y_11 ∝ +x and Y_1,-1 ∝ +y. Each element's field is taken as constant over the element and the harmonics are integrated over its facets with exact sub-triangle solid angles (4^level per triangle); the covered solid angle is normalized to 4π.
